## Sobre o Projeto
O **NeoGym** é uma aplicação web voltada para a apresentação e pré-matrícula de alunos em uma academia de ginástica e musculação. A plataforma visa simplificar a escolha de planos e modalidades de treino, oferecendo uma interface moderna, semântica e acessível.

---

## Tecnologias Utilizadas
- **HTML5 Semântico:** Estruturação limpa com elementos semânticos (`header`, `main`, `section`, `footer`, `fieldset`, `legend`).
- **CSS3:** Estilização responsiva e organizada em pastas.
- **Acessibilidade (WCAG):** Relação `for`/`id` em formulários, tags interativas corretas e navegação por leitores de tela.
- **Git & GitHub:** Versionamento com *Conventional Commits*, branches por funcionalidade e Pull Requests com *merge commits*.
